# BuildEase (Projeto Integrador I - DSM) (Nome Provisório)

Imagine que você precisa construir o segundo andar da sua casa. Normalmente, o primeiro passo seria pedir indicações a amigos para encontrar um pedreiro competente e de confiança.

Nossa plataforma web resolve exatamente essa dor, conectando clientes a profissionais da construção civil de forma rápida e transparente. Pelo sistema, o cliente filtra pedreiros por especialidade, compara faixas de preço, verifica avaliações e descobre na hora se o orçamento já inclui os materiais ou contempla apenas a mão de obra.

Além disso, os próprios pedreiros podem publicar fotos de suas últimas obras na plataforma. Isso permite que o cliente avalie na prática a qualidade do trabalho antes de contratar e cria uma comunidade colaborativa, onde outros profissionais também podem visualizar, avaliar e dar dicas construtivas para aprimorar os serviços.

## 📋 Sobre o Projeto
Este projeto está sendo desenvolvido para integrar as disciplinas de **Engenharia de Software I**, **Design Digital** e **Desenvolvimento Web I**.

### Principais Funcionalidades
- **Perfil 1 (Cliente):** Pode buscar e avaliar itens.
- **Perfil 2 (Profissional):** Pode cadastrar serviços e gerenciar pedidos.
- **Integração:** Consumo de API externa (ex: ViaCEP).

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript
- **Prototipação:** Figma
- **Documentação e Diagramas:** UML / MER
- **Gestão Ágil:** Trello (Kanban)
